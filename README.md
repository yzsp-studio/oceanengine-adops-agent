## 🇬🇧 English

A read-only monitoring and data-analysis skill for OceanEngine ad accounts, querying authorised account reports through the official Remote MCP. It analyses core delivery metrics, identifies long-tail candidates and diagnoses performance problems, then outputs observations and suggestions. The safety boundary is explicit: it never creates, pauses, enables, deletes or adjusts any ad. Built for day-to-day monitoring and post-campaign review of authorised accounts.

### ✨ What it does

- Query authorised account reports and summarise core delivery metrics
- Identify long-tail candidates worth watching
- Diagnose performance issues and output observations plus suggestions
- Run a capability check on first call to confirm the available scope
- Read-only boundary: never create, pause, enable, delete or adjust ads
- Separates data display from safety boundaries to prevent over-reach
